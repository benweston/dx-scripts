# `> | scripts`

<div align="justify">

> Collection of utility and automation scripts grouped by category.  Each subdirectory includes scripts related to a specific area of system administration or package management.   

</div>

## Usage

<div align="justify">

Scripts can be executed directly from their respective folders.   
Scripts might require elevated privileges (e.g., `sudo`) depending on their purpose.   

Example:   

```bash
cd system
sudo ./<script-name>.sh
```

</div>
